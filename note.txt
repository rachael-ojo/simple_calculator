SIMPLE CALCULATOR - PROJECT NOTES

This project is a simple calculator built using HTML, CSS, and JavaScript.

The purpose of this project was to practice JavaScript fundamentals and understand how HTML, CSS, and JavaScript work together to create an interactive web application.

FEATURES IMPLEMENTED

- Addition
- Subtraction
- Multiplication
- Division
- Decimal calculations
- Clear button
- Backspace button
- Keyboard support
- Enter key for calculations
- Escape key to clear the display
- Error handling for invalid calculations
- Prevention of multiple operators
- Prevention of invalid decimal input
- Responsive design for different screen sizes

WHAT I LEARNED

While building this calculator, I learned how to:

- Select HTML elements using JavaScript
- Add event listeners
- Handle button clicks
- Handle keyboard events
- Create and use JavaScript functions
- Manipulate the DOM
- Validate user input
- Perform calculations using JavaScript
- Make a webpage responsive
- Debug JavaScript errors using the browser console

CHALLENGES

One of the challenges I encountered was making the keyboard Enter key work correctly without adding unwanted numbers to the display.

I also worked on handling decimal numbers, preventing multiple decimal points, preventing multiple operators, handling division by zero, and limiting the number of digits displayed on the calculator.

PROJECT COMPLETION

The calculator was tested using both the calculator buttons and the computer keyboard. It was also tested at different screen sizes to make sure the layout remained usable.

This project helped me improve my understanding of JavaScript and gave me more confidence in building interactive web applications.
